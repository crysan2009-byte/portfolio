# Meu Portfólio Profissional

**Nome do aluno:** Crysan Araújo dos Santos  
**Descrição do portfólio:** Site de portfólio pessoal desenvolvido para apresentar meus dados acadêmicos, habilidades técnicas e principais projetos de desenvolvimento.  
**Tecnologias utilizadas:** HTML5, CSS3 e Bootstrap 5.  
**Link do site publicado:** [Acesse o portfólio aqui](https://SEU-USUARIO.github.io/SEU-REPOSITORIO)  

## 🚀 Funcionamento do Projeto
O site é uma página única (*Single Page Application*) com navegação fluida por meio de um menu superior fixo. Ele integra seções claras de apresentação pessoal, catálogo de habilidades, listagem de projetos em formato de cards e canais de contato direto.

## ✨ Descrição do Recurso Novo Adicionado
Como recurso diferencial além do modelo base visto em sala, foi incluída uma **Seção de Habilidades** dedicada e um **Efeito Visual de Transição (*Hover*)** em todos os blocos e cards do site.

### Como esse recurso foi implementado
O efeito visual foi programado utilizando classes e propriedades de transição do CSS3 (`transition: transform 0.3s ease, box-shadow 0.3s ease;`). Quando o usuário posiciona o cursor sobre os elementos de habilidades ou projetos, a pseudoclasse `:hover` aplica uma elevação suave na vertical (`transform: translateY(-8px);`) acompanhada de um sombreamento dinâmico.
